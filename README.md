# cats_codes
Versiones de cats_pose (entrenamiento)

## cats_pose_v03 
Primera versión bastante fea de entrenamiento.
Dataset con imagenes consecutivas capturadas de varias trayectorias entrenado con primera versión del mundo de gazebo.
- Dataset: [dataset_1](https://drive.google.com/drive/folders/18E6CwBWxQE8mEu-caHqZziRyw9V66Dnz?usp=drive_link)


## cats_pose_local_v01
Adaptación de cats_pose_v03 para correr entrenamiento de manera local usando la GPU de la PC
- Dataset: [dataset_3](https://drive.google.com/drive/folders/1aC88Jw-UjBabNftDLtgXRgOiWB-Vtail?usp=sharing)
- Resultados: [Training_1](https://drive.google.com/drive/folders/1XDXkbwspKQHqVHVUJ29evWNVljqU4s2z?usp=sharing)

- Resultados: [Training_2](https://drive.google.com/drive/folders/14LZavmovI7NraTS6kjBR9xoDMwbPwgHR?usp=sharing) , [Training_3](https://drive.google.com/drive/folders/1nu5ekLi5kluL0sJZ7Bjt-GBd0IfLt1hN?usp=sharing) , [Training_4](https://drive.google.com/drive/folders/1Sr8Ttur5_uFQZyEsflKti51RcKg1kCzR?usp=sharing)
